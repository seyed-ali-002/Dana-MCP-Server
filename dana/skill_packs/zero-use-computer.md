# Desktop control guidance

- Prefer `desktop_control` actions with explicit coordinates or keys.
- Screenshot only when spatial context is required.
- Batch related pointer actions when possible.
- If the Zero Use Computer binary (`zero`) is installed, prefer its accessibility tools for UI trees; otherwise use Dana desktop_control.
