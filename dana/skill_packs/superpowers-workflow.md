# Superpowers-style workflow

Before large implementation:
1. Clarify the real goal in one sentence.
2. Outline a short plan (3–7 steps).
3. Implement the smallest vertical slice.
4. Verify with tests or a concrete check.
5. Report what changed and what remains.

If requirements are ambiguous, ask one focused question instead of guessing.
