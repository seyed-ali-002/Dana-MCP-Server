# 17 — سیاست مستندسازی اجباری (Documentation Policy)

> **وضعیت:** الزام‌آور (Mandatory)  
> **نسخه سند:** 1.0.0  
> **تاریخ:** 2026-11-22  
> **مخاطب:** انسان و عامل AI  
> **مراجع:** `07-development-guidelines.md` · `AGENTS.md` · `11-ai-guardrails.md`

---

## 1. اصل

**هر مرحلهٔ تغییر، پیاده‌سازی یا ویرایش که رفتار محصول، API، قرارداد MCP، UI، امنیت یا عملیات را عوض کند باید در همان PR/commit مستند شود.**

بدون به‌روزرسانی مستند مرتبط، کار **تمام‌شده محسوب نمی‌شود** (Definition of Done ناقص است).

---

## 2. چه زمانی مستند اجباری است؟

| نوع تغییر | مستند حداقلی |
|-----------|---------------|
| رفتار کاربرنهایی / CLI / Desktop | `README.md` یا `README_FA.md` / `README_EN.md` + در صورت نیاز SRS |
| الزام کارکردی/غیرکارکردی جدید یا تغییر وضعیت | `09-srs.md` |
| milestone نسخه / اولویت roadmap | `08-development-roadmap.md` |
| API setup، connector، SuperMCP، Godot proxy | `16-connectors-supermcp-godot.md` + SRS در صورت API عمومی |
| معماری / جریان داده جدید | `01-architecture.md` یا ADR در `docs/adr/` |
| نصب / استقرار / env | `04-setup-deployment.md` + `.env.example` |
| امنیت، path policy، subprocess | `11-ai-guardrails.md` + SRS/NFR |
| باگ‌فیکس رفتاری مهم | `CHANGELOG.md` + در صورت نیاز `15-post-2.0-fix-notes.md` |
| فقط refactor داخلی بدون تغییر رفتار | توضیح کوتاه در commit؛ SRS اختیاری با عبارت «بدون تغییر SRS» |

---

## 3. چک‌لیست اجباری قبل از اعلام Done

```text
[ ] شناسه الزام/TECH/Roadmap مشخص شده (یا «بدون تغییر SRS» در PR)
[ ] فایل(های) مستند مرتبط ویرایش شده‌اند
[ ] در صورت لمس SRS/Roadmap/AI docs: bash scripts/sync_living_docs.sh
[ ] CHANGELOG.md برای تغییرات کاربر-قابل‌مشاهده به‌روز شده
[ ] هیچ secret / مسیر شخصی / توکن در مستند نیست
[ ] لینک‌های متقابل در README فهرست اسناد درست است
```

---

## 4. همگام‌سازی آینه‌ها

اسناد زندهٔ اصلی در `project_description_md/` هستند. پس از ویرایش:

```bash
bash scripts/sync_living_docs.sh
```

این اسکریپت نسخه‌های `docs/*.md` را از canonical کپی می‌کند.

---

## 5. قالب حداقلی برای یادداشت پس از مرحله

برای هر مرحلهٔ غیرپیش‌پاافتاده در `CHANGELOG.md` یا یادداشت fix:

```markdown
### YYYY-MM-DD — عنوان کوتاه
- **چه:** …
- **چرا:** …
- **کجا (فایل‌ها):** …
- **تأثیر کاربر/API:** …
- **تست:** pytest / smoke / دستی
```

---

## 6. ممنوعیت‌ها

| ممنوع | دلیل |
|--------|------|
| «بعداً مستند می‌کنم» بدون issue/TODO در همان PR | فراموشی سیستماتیک |
| فقط commit message به‌جای SRS وقتی رفتار عوض شده | از دست رفتن ردیابی الزام |
| کپی‌پیست توکن/مسیر شخصی در docs | امنیت و حمل‌پذیری |
| دو منبع حقیقت متناقض بدون sync | سردرگمی AI و انسان |
