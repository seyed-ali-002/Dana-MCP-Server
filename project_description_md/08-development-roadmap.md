## 1. هدف این سند

این فایل مرجع رسمی **برنامه‌ریزی توسعه آیندهٔ Dana** است. هر پیشنهاد فیچر، هر اسپرینت، و هر افزایش نسخهٔ minor/major باید با این سند هم‌راستا باشد و پس از تحویل، همین‌جا به‌روز شود.

### قوانین نگهداری

1. قبل از شروع کار روی نسخهٔ جدید، بخش مربوط به آن نسخه در این فایل خوانده شود.
2. پس از merge هر milestone مهم، وضعیت آیتم‌ها (`planned` / `in_progress` / `done` / `deferred` / `cancelled`) به‌روز شود.
3. هر آیتم باید **معیار پذیرش (Acceptance Criteria)** داشته باشد؛ بدون معیار، وارد اسپرینت نشود.
4. فیچرهای «فان» نباید مسیر پایداری اتصال و نصب را متوقف کنند.
5. تغییرات رفتاری کاربرنهایی باید در `README*.md` و در صورت نیاز در SRS نیز منعکس شوند.

### قالب وضعیت آیتم

| نماد | معنی |
|------|------|
| `planned` | برنامه‌ریزی‌شده، هنوز شروع نشده |
| `in_progress` | در حال پیاده‌سازی |
| `done` | تکمیل و در main/release |
| `deferred` | به تعویق افتاده با دلیل |
| `cancelled` | لغو شده با دلیل |

## 2. اصول اولویت‌بندی

1. **پایداری اتصال و اجرا روی همهٔ OS** بالاتر از هر فیچر جدید است.
2. **First-run بدون گیر** (Tailscale / Funnel / sudo / browser login) اولویت محصول است.
3. **سازگاری کلاینت‌های MCP** (به‌ویژه DeepSeek و Streamable HTTP) باید حفظ شود.
4. هر وابستگی خارجی جدید باید قابل‌غیرفعال‌سازی و بدون شکستن هسته باشد.
5. حجم installer و زمان بیلد نباید بدون توجیه رشد کند.

## 3. وضعیت فعلی مبنا (Baseline — v1.6.17)

### 3.1 قابلیت‌های پایدار (تقریبی)

- MCP Server لوکال روی پورت پیش‌فرض `8765` مسیر `/mcp`
- احراز هویت با توکن پایدار و URL توکن‌دار
- Tailscale Funnel برای endpoint عمومی
- Desktop Control Center (React + Tauri 2)
- CLI: install / start / stop / connect / doctor / gui
- Tool registry، orchestration (`dana_parallel_call` و مشابه)
- Path policy و `clean_subprocess_env` برای محیط PyInstaller/AppImage
- Skill packs اختیاری
- SuperMCP assistant (قابل دسترس عمومی، بدون مسیر شخصی)
- Release خودکار از GitHub Actions (Linux / Windows / macOS)

### 3.2 بدهی فنی شناخته‌شده (باید در 1.7 بسته شود)

| شناسه | موضوع | شدت |
|--------|--------|------|
| TECH-01 | بازیابی session در Streamable HTTP (`Session not found`) | بالا |
| TECH-02 | پایداری PUBLIC endpoint پس از قطع/وصل شبکه یا ری‌استارت | بالا |
| TECH-03 | First-run Funnel + sudo + تأیید مرورگر بدون گیر | بالا |
| TECH-04 | Single-instance واقعی از tray و لانچر | متوسط |
| TECH-05 | لاگ ابزارها با جزئیات collapsible یکدست | متوسط |
| TECH-06 | نوتیفیکیشن دسکتاپ + صدا (قابل خاموش‌کردن) | متوسط |
| TECH-07 | UI responsive هنگام resize | پایین |
| TECH-08 | یکدست‌سازی استایل کنترل‌ها (dropdown تم، skills) | پایین |
